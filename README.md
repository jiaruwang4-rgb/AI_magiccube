# AI魔方手机NFC测试页

## 已支持的卡牌编号

- 任务卡：T01、T02
- 功能卡：F01、F02、F03
- 风险卡：R01、R02
- 侦探卡：D01

标签可以写成纯文本编号，也可以写成末尾含编号的网址。

## 使用条件

网页NFC需要：

1. 支持NFC的安卓手机；
2. Chrome浏览器；
3. 通过HTTPS打开本页面；
4. 点击“开始NFC感应”并授权；
5. 页面保持在前台，手机保持解锁。

在电脑或不支持Web NFC的手机上，可以展开“没有NFC？使用模拟刷卡”测试完整游戏流程。

## 推荐测试顺序

1. T01或T02任务卡；
2. F01、F02或F03功能卡；
3. R01或R02风险卡；
4. 填写使用规则；
5. 完成任务。

## 发布前检查

- 必须使用HTTPS地址；
- 确认卡牌内写入的是T01等编号或包含编号的网址；
- 关闭手机自动锁屏；
- 取下磁吸或过厚手机壳；
- 给教师保留模拟刷卡作为现场备用。
